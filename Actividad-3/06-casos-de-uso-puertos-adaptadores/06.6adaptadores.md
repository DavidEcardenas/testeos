# 06.6 — Adaptadores

Los adaptadores viven en `/src/Infrastructure` y se implementan en la
Actividad 4. Aquí solo se documenta su intención.

| Adaptador | Implementa | Tecnología prevista |
|---|---|---|
| `EfDeliveryRepository` | `IDeliveryRepository` | EF Core + PostgreSQL |
| `HttpCourierAdapter` | `ICourierAvailabilityPort` | HTTP + REST |
| `HttpRouteAdapter` | `IRouteCapacityPort` | HTTP + REST |
| `InventoryHttpAdapter` | `IStockReservationPort` | HTTP interno entre módulos |
| `RabbitEventPublisher` | `IEventPublisher` | RabbitMQ / bus interno |

## Reglas

- Un adaptador implementa **un solo** puerto.
- Los adaptadores no contienen reglas de negocio.
- Si un adaptador falla, el caso de uso debe poder manejarlo (reintentos,
  cola o estado intermedio).
