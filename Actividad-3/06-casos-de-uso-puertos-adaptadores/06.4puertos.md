# 06.4 — Puertos

Los puertos los define la Aplicación. Expresan **qué necesita** el caso de
uso, no **cómo se implementa**.

| Puerto | Dirección | Propósito | Adaptador futuro (Actividad 4) |
|---|---|---|---|
| `IDeliveryRepository` | Salida | Persistir y recuperar entregas | EF Core / PostgreSQL |
| `ICourierAvailabilityPort` | Salida | Consultar disponibilidad del repartidor | Servicio de repartidores / BD |
| `IRouteCapacityPort` | Salida | Verificar capacidad de ruta | Servicio de rutas / BD |
| `IStockReservationPort` | Salida | Verificar reserva de stock | Módulo Inventario (interno) |
| `IEventPublisher` | Salida | Publicar eventos de dominio | Bus interno / cola |
| `AssignCourierUseCase` | Entrada | Orquestar la asignación | Controlador REST / consumidor de eventos |

## Regla de dependencias

- Los puertos viven en `/src/Application`.
- Las implementaciones viven en `/src/Infrastructure`.
- El dominio no conoce ninguno de los dos.
